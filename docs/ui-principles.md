# UI Principles

These principles are immutable guidance for the security-automation-go UI.

## Principles

1. Signal over spectacle.
2. Performance first.
3. Server-first rendering.
4. Observability and administration are separate concerns.
5. AI assists, but never replaces evidence.
6. Progressive disclosure by default.
7. Offline-first degradation is required.
8. Large datasets must remain usable.
9. No heavy front-end dependencies without strong justification.
10. The Dashboard is the primary operational entry point.

## Notes

- The UI is a projection of system state.
- Business logic and mutations stay on the server.
- Read-only investigation surfaces must remain read-only.
