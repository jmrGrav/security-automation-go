# Compatibility Checklist

- Python files remain unchanged and continue to be the production source of truth.
- Go code lives in a separate directory and separate deployment units.
- Every current Python responsibility has a named Go package owner.
- Cloudflare access-rule sync preserves add/remove semantics.
- Cloudflare access-rule tags: `crowdsec-local-ban`, `modsec-ban`, `crowdsec-cidr-ban`.
- Cloudflare list sync preserves additive-only CrowdSec allowlist behavior.
- Cloudflare cleanup preserves `easycron` keep-note behavior (case-insensitive).
- CrowdSec allowlist exclusion pattern: `immuniweb`.
- Scenario categories for AbuseIPDB reporting:
  - `http-sensitive-files`, `http-probing`, `http-scan`, `http-bad-user-agent`, `http-wordpress-scan`, `http-crawl-non_statics`, `http-exploit`, `vpatch-env-access`, `vpatch-git-config`: `21,19`
  - `ssh-bf`, `ssh-slow-bf`, `ssh-time-based-bf`, `ssh-refused-conn`, `ssh-cve`: `22`
  - `mcp-oauth-bruteforce`: `18,21`
  - `mcp-oauth-ratelimit`, `mcp-oauth-scanner`, `mcp-oauth-bad`: `21,19`
- Recidivist escalation rules: 2nd ban -> 24h, 3rd+ -> 7 days (`168h`).
- ModSecurity: score >= 5, ban duration 2h (`7200s`).
- CIDR /24: 2+ distinct IPs in 7 days, ban duration 24h.
- Cloudflare WAF: 3+ hits in 5 minutes.
- AbuseIPDB categories: `21` for ModSec, `21,19` for WAF blocks.
- CrowdSec allowlist matching supports both exact IPs and CIDR membership.
- IPv6 normalization rules are defined before sync logic is implemented.
- AbuseIPDB deduplication keys are preserved.
- Recidivist count and duration rules are preserved.
- ModSecurity temporary-ban duration and cleanup behavior are preserved.
- CIDR `/24` threshold and retention semantics are preserved.
- Cloudflare WAF polling cursor semantics are preserved.
- JSON state file schemas are documented before implementation.
- All outbound HTTP paths have timeouts and retry policy.
- All long-running loops are cancellable via `context.Context`.
- No package depends on global mutable state.
- Systemd examples preserve restartability and environment-based secrets.
